2. TONE PARTITION  (voice prompts) — trivially moddable
   Format: directory of [uint32 size][name\0] ... then raw files back-to-back from offset 0x400.
   17 files, extracted bit-exact (83,143/83,143 bytes consumed), all valid MP3/WAV:
     power_off low_power close key_up adpt call noise pass_those disconnected hangup
     connected space_close game_mode_open slip_max slip slip_min key
   MP3 = 16/22/48 kHz mono 24-56 kbps; WAV = 16-bit PCM mono 8/48 kHz.
   'space_close' = spatial audio off, 'game_mode_open' = low-latency mode, 'adpt' = adaptive ANC.

3. EQ2P PARTITION  (magic 'SLEQ') — plain float table
   Records: [u8 kind][u8 param][u16 band][f32 value], 8-byte stride from offset 26.
   kind 0x00 = main playback EQ, param 0x00=freq Hz, 0x01=Q, 0x02=gain dB.
   FACTORY H2S TURBO TUNING (10-band parametric):
      80 Hz  Q0.71  -2.0 dB     2421 Hz Q1.5  +3.8 dB     9750 Hz Q5.2  -0.5 dB
     130 Hz  Q1.2   -1.9 dB     4100 Hz Q2.0   0.0 dB    12200 Hz Q4.7  +6.3 dB
     240 Hz  Q0.71  -4.6 dB     6100 Hz Q5.5  -4.5 dB      900 Hz Q1.0  +0.5 dB
     420 Hz  Q1.0   -1.3 dB     7990 Hz Q2.2  +4.5 dB
   => bass/low-mid scooped, presence + air lifted: a bright AirPods-Pro-style target.
   kinds 0x02-0x05 = additional band tables (mic / ANC / sidetone paths; 25 Hz-16 kHz).

4. SENC PARTITION  (magic 'SENC') — same [u16 group][u16 idx][f32] param table.
   Sensor / wear-detect / motion calibration constants (e.g. -25, -60, 125, 0.985).
